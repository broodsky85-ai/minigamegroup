개인정보처리방침

블록 펀치: Block Punch (com.broodsky85.blockpunch) · 시행일 2026년 9월 12일

현재 버전의 블록 펀치는 계정이나 로그인을 요구하지 않으며, 게임 진행과 기록을 이용자의 기기 안에만 저장합니다. 개발자 서버, 광고, 분석 도구, 인앱 결제를 사용하지 않고 개인정보를 수집하거나 제3자에게 전송하지 않습니다.

1. 수집·공유하는 정보

현재 버전은 이름, 이메일, 전화번호, 위치, 연락처, 사진, 파일, 광고 식별자 또는 기기 식별자를 수집하거나 공유하지 않습니다. 인터넷 권한을 사용하지 않으며 외부 서버와 통신하지 않습니다.

2. 기기에 저장되는 정보

block-punch-state-v1이라는 기기 내부 저장 영역에 다음 정보가 저장됩니다.

  • 진행 중인 판의 시드와 확정 행동 기록
  • 완료 횟수, 최고 점수와 최근 기록
  • 교육 완료 여부와 소리·진동·동작 감소 설정

이 정보는 개발자나 제3자에게 전송되지 않습니다. 앱의 저장공간을 지우거나 앱을 삭제하면 함께 삭제됩니다.

3. 앱 권한

짧은 게임 반응을 위한 진동 권한만 사용합니다. 진동은 앱 설정에서 끌 수 있습니다. 카메라, 마이크, 위치, 연락처, 저장소, 인터넷 및 광고 ID 권한은 사용하지 않습니다.

4. 도전 코드

이용자가 결과 화면에서 도전 정보를 직접 복사할 수 있습니다. 도전 코드에는 같은 판을 재현하기 위한 규칙 버전, 생성 버전과 숫자 시드만 포함되며 이용자를 식별하는 정보는 포함되지 않습니다. 앱이 도전 코드를 자동으로 전송하지 않습니다.

5. 아동의 개인정보

앱은 개인정보를 수집하지 않습니다. 아동을 대상으로 개인정보를 요청하거나 맞춤형 광고를 제공하지 않습니다.

6. 향후 광고 도입

현재 배포본에는 광고가 없습니다. 향후 광고나 분석 기능을 추가할 경우 실제 수집·공유 항목, 사용 목적, 제3자 서비스와 이용자 선택 방법을 반영하여 이 방침과 Google Play의 광고 및 데이터 보안 선언을 먼저 갱신합니다.

7. 방침 변경

앱 기능이나 정보 처리 방식이 바뀌면 이 페이지의 내용과 시행일을 갱신합니다.
